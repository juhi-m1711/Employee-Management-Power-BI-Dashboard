# 📊 Employee Management Dashboard – Power BI

## Overview  
This project is my **first Power BI dashboard**, created to analyze employee **salary and bonus data** across departments, business units, and demographics using interactive visualizations.

---

## Analysis Performed  
- Annual and average salary by department  
- Bonus percentage analysis  
- Salary distribution by gender  
- Salary comparison across business units  

---

## Filters Used  
- Job Title  
- Department  
- Business Unit  
- City  

---

## Tools & Technologies  
- Microsoft Power BI  
- Power Query  
- DAX (Basic)
